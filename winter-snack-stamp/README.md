# 🏮 우리 반 겨울 간식 포장마차 (겨울간식 스탬프)

수업을 열심히 들으면 스탬프를 받고, 스탬프를 모아 붕어빵·호빵으로 바꾸는 4주 학급 활동 앱이에요.
구글시트 + Google Apps Script 웹앱으로 돌아가서, 교실 패드·학생 폰·교무실 PC가 같은 데이터를 봐요.

| 화면 | 주소 | 누가 |
|---|---|---|
| 🏫 교실 패드 | `웹앱주소?v=pad` | 교과 선생님 (교사 PIN) |
| 📒 담임 관리 | `웹앱주소?v=admin` | 담임 (관리자 PIN) |
| 🎫 학생 화면 | `웹앱주소?s=개인코드` | 학생 (QR 카드로 들어와요. 자기 것만 보여요) |

자세한 규칙과 화면 설계는 [`PLAN.md`](PLAN.md)에 있어요.

## 설치 (처음 한 번, 10분쯤)

학교 구글 계정(Workspace)은 외부 공개가 막혀 있을 수 있어서 **개인 Gmail 계정**을 권장해요.

1. 구글 드라이브에서 **새 구글 시트**를 만들어요. 이름은 예를 들어 `겨울간식 스탬프`.
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을 붙여 넣어요.
4. 왼쪽 **파일 ＋ → HTML**을 눌러 이름을 `Index`로 만들고, [`Index.html`](Index.html) 내용을 붙여 넣어요.
5. 왼쪽 **⚙ 프로젝트 설정**에서 시간대를 **(GMT+09:00) 서울**로 맞춰요.
   (또는 "편집기에서 appsscript.json 매니페스트 파일 표시"를 켜고 [`appsscript.json`](appsscript.json) 내용을 붙여 넣어요.)
6. 위쪽 함수 목록에서 `setup`을 고르고 **▶ 실행**을 눌러요. 처음 한 번 권한을 물어보면 허용해요.
   ("확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동**을 눌러요. 내가 만든 스크립트라 괜찮아요.)
   시트에 `학생`, `기록`, `설정`, `재고` 탭이 생겨요.
7. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 골라요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나오는 **웹 앱 URL**을 복사해 둬요.
8. 웹 앱 URL을 열고 **📒 담임 관리**로 들어가요. 처음 관리자 PIN은 `0000`, 교사 PIN은 `1234`예요.
   1. **설정** 탭: 학급 이름, **PIN 두 개 바꾸기(꼭!)**, 활동 시작·끝 날짜, 교시 시간표, 과목을 넣고 저장해요.
   2. **명단·QR** 탭: 엑셀에서 번호·이름 두 칸을 복사해 붙여 넣고 **명단 저장** → **QR 카드 인쇄**.
   3. **재고·간식 준비** 탭: 맛별로 사 온 개수(입고 수량)를 넣어요. 활동 중에 더 사 오면 늘려요.
9. 교실 패드에서 `웹앱주소?v=pad`를 열고 홈 화면에 추가(즐겨찾기)해 두면 편해요.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 해야 웹앱에 반영돼요. 주소는 그대로예요.

## 쓰는 법

**교실 패드 (교과 선생님)**
- **🔓 수업 시작** → 교사 PIN → 교시(지금 시각으로 골라 둬요)·과목 → 수업 시작.
- 이름을 눌러 고른 뒤 아래 버튼을 눌러요. 여러 명을 한 번에 줄 수 있어요.
  - ⭐ 열심히 +1, 🙋 적극 참여 +1: 같은 수업에서 학생마다 한 번씩만 (이미 받은 학생은 저절로 건너뛰어요)
  - 👑 MVP: 1명만 골랐을 때, 수업마다 1명
  - ＋ 더 주기: 개수·이유를 골라서 / － 빼기: 개수·이유(잠·방해·기타)를 고르고 한 번 더 확인
  - 🔔 수업 준비 **전원 +1**: 수업마다 한 번
- 잘못 눌렀으면 **↶ 되돌리기**. 화면에 먼저 보이고 서버에는 차례로 저장돼요. 연결이 끊기면 "다시 시도 중"이 보이고 저절로 다시 보내요.
- **수업 마치기**를 누르면 요약이 나오고 잠겨요. 수업 시작 뒤 60분이 지나도 저절로 잠겨요.

**학생 (개인 QR 링크)**
- 처음 들어오면 규칙 안내를 끝까지 읽어야 시작해요. 그다음부터는 **📜 규칙** 버튼으로 다시 봐요.
- 받은 스탬프는 🥣 반죽으로 쌓이고, **붕어빵 쿠폰(30칸)**이나 **호빵 쿠폰(45칸)**을 눌러 쿠폰 창에서 찍어요.
  찍은 칸에는 붕어빵·호빵 스티커가 붙고, 칸이 찰수록 위쪽 그림이 노릇노릇·따끈따끈해져요.
- 다 채우면 맛을 고르고(선착순 재고) 교환권이 나와요.
- 🐷 저금통 기부, 💌 친구 칭찬하기, 🧾 최근 기록도 볼 수 있어요.

**담임 관리**
- 현황 · 교환권(출력·교환 완료) · 재고·간식 준비 · 칭찬(지우기) · 기록(취소·직접 더하기/빼기) · 명단·QR · 통계·저금통(보상 완료, 1주차 점검, 수업 준비 성공 기록) · 설정
- 교환권 인쇄: 크롬에서 A4, 배율 100%, **배경 그래픽 켜기**. 크게(A4 6장) / 작게(A4 12장).

## 그림 바꾸기 (ChatGPT로 그린 그림)

지금은 앱이 직접 그린 기본 그림(스티커, 굽기·찌기 5단계, 맛별 그림, 저금통 등)이 들어 있어요.
[`ART_PROMPTS.md`](ART_PROMPTS.md)의 파일 이름 그대로 그림(PNG·JPG·WebP)을 `art/` 폴더에 넣고 아래를 실행하면 `Index.html`에 그림이 들어가요.
GitHub 웹으로 올릴 때는 5~10장씩 나눠 올려요 ([`art/README.md`](art/README.md)).
그다음 Apps Script의 `Index.html`을 새 내용으로 바꾸고 새 버전으로 배포해요.

```bash
python3 tools/embed.py
```

## 개인정보와 보안

- 학생 명단은 구글시트에만 저장되고 이 저장소에는 올리지 않아요. (`.gitignore`가 `*.xlsx`, `*.xls`, `*.csv`를 빼요)
- 학생은 8자리 개인 코드 링크로 **자기 정보만** 읽고 쓸 수 있어요. 다른 학생의 스탬프·기부는 보이지 않아요.
- 웹앱은 "모든 사용자"에게 열려 있어서, 패드·관리 화면은 PIN으로 지켜요. PIN을 5번 틀리면 5분 동안 잠겨요. **처음 PIN은 꼭 바꿔요.**
- 모든 일은 `기록` 탭에 한 줄씩 쌓여요. 취소해도 줄은 남고 `취소` 칸에 Y만 표시돼요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `Code.gs` | 서버 (시트 읽기·쓰기, 규칙 계산, PIN, 잠금) |
| `Index.html` | 화면 전부 (교실 패드, 담임 관리, 학생 화면, 교환권 인쇄, 그림, QR 라이브러리) |
| `appsscript.json` | Apps Script 설정 (시간대 Asia/Seoul, 웹앱) |
| `PLAN.md` | 기획서 |
| `HANDOFF.md` | 다음 세션 인계문 |
| `ART_PROMPTS.md` | ChatGPT 그림 프롬프트 |
| `tools/embed.py` | QR 라이브러리와 그림을 `Index.html`에 넣는 도구 |
| `vendor/` | qrcode-generator 1.4.4 원본 |
| `tests/` | 서버 규칙 테스트, 화면 확인 스크립트 (개발용) |

## 개발용 확인

```bash
node --test tests/*.test.js
```

```bash
node tests/e2e.js /tmp/shots
```

`tests/gas-mock.js`가 SpreadsheetApp 등을 흉내 내서 `Code.gs`를 Node에서 그대로 돌려요. `e2e.js`는 Chromium에서 화면을 띄워 스크린샷을 찍어요.
