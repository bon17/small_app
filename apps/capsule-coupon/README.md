# 캡슐 뽑기권 만들기

구글시트에 정리된 캡슐 뽑기 대기 명단(엑셀)을 불러와서, 학생별 **캡슐 뽑기권**을 A4로 출력하는 앱입니다.
기프티콘처럼 떼는 점선과 반원 홈이 있는 귀여운 쿠폰 모양이에요.

## 쓰는 법

1. `index.html` 파일을 브라우저(크롬·엣지 권장)로 엽니다. 설치는 필요 없고, 인터넷이 없어도 동작해요.
2. 구글시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 로 명단을 저장한 다음, 앱의 **엑셀 파일 선택**에 넣습니다.
3. 쿠폰 설정을 확인합니다.
   - 학교 이름: 기본값 `기산중학교`
   - 안내 문구: 기본값 `본교무실에 캡슐 뽑으러 오세요~`
   - 발급일: 기본값 오늘
   - 유효기간: 기본값 2주 뒤. 비우면 쿠폰에 표시하지 않아요.
   - A4 한 장에 들어갈 쿠폰 수: 8 / 10 / **12(기본)** / 16 / 24장
   - 캡슐 그림
4. 학생을 고릅니다.
   - 목록은 학생 한 명당 한 줄이고, 옆에 뽑을 쿠폰 장수가 보여요.
   - 줄을 누르면 선택되고, 미리보기도 그 학생으로 바뀝니다. 학번·이름으로 검색할 수 있어요.
5. 출력 버튼을 누릅니다. 학생마다 장수만큼 쿠폰이 이어서 나오고, 쿠폰에는 `1/3`, `2/3`처럼 몇 번째 장인지 표시돼요.
   - **선택한 학생 출력**: 체크한 학생만 출력합니다.
   - **목록 전체 출력**: 지금 목록에 보이는 학생을 모두 출력합니다.
   - A4 용지가 10장을 넘으면 출력 전에 한 번 더 물어봐요.
6. 인쇄 창에서 용지는 **A4**, 배율은 **기본값(100%)** 으로 두고 인쇄합니다. 점선을 따라 자르면 됩니다.

## 엑셀 형식과 쿠폰 장수

- 위쪽 30줄 안에서 `이름`(또는 `성명`) 제목이 있는 줄을 찾고, 그 아래를 명단으로 읽습니다.
- `학번` 제목도 있으면 함께 읽어요. 열 순서나 숨긴 열은 상관없습니다.
- 학번과 이름이 같은 줄은 한 학생으로 묶습니다.
- 시트가 여러 개면 제목 줄이 있는 시트를 모두 찾아서 위쪽 **시트** 칸에서 고를 수 있어요.
- 학생별 쿠폰 장수는 **쿠폰 장수** 칸에서 정합니다.
  - **'○○' 칸의 숫자만큼**: 숫자로 된 칸(예: `학생별 정산` 시트의 `남은 횟수`)의 값만큼 뽑아요.
  - **줄 수만큼**: 같은 학생의 줄 수만큼 뽑아요. 예를 들어 `기록` 시트에 3줄이 있으면 3장이에요.
- 처음 불러올 때 자동으로 고르는 기준은 이래요.
  - 시트: 숫자 칸이 있는 시트(예: `학생별 정산`)를 먼저 고릅니다.
  - 칸: 이름에 `남은`·`잔여`·`미지급`이 들어간 칸 → `장수`·`쿠폰` → `횟수`·`예약` 순으로 고릅니다. `지급 횟수`처럼 이미 받은 걸 세는 칸은 뒤로 미뤄요.
  - 자동으로 고른 칸이 맞는지 꼭 확인하고, 아니면 직접 바꾸세요.
- 0장인 학생은 목록에서 빠지고, 이름이 빈 줄은 건너뜁니다.
- 일련번호(No.)는 불러온 명단 순서대로 학생의 장수만큼 이어서 붙어요. 엑셀을 새로 받으면 장수가 바뀔 수 있어서 번호도 달라질 수 있어요.
- `.csv` 파일도 읽을 수 있어요.

## 개인정보

- 엑셀 파일은 브라우저 안에서만 읽고, 어디로도 전송하지 않습니다.
- 이 폴더의 `.gitignore`는 `*.xlsx`, `*.xls`, `*.csv` 파일을 제외합니다. 학생 명단이 실수로 저장소에 올라가지 않게 하려는 거예요.
- 브라우저에 저장되는 것은 학교 이름, 안내 문구, 한 장당 쿠폰 수, 직접 바꾼 캡슐 그림뿐입니다. 학생 명단은 저장되지 않아요.
