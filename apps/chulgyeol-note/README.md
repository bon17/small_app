# 출결노트

출결 관리부터 신고서 출력까지. 출결판에서 학생 이름이나 칸을 눌러 출결을 넣으면, 서류함에서 우리 학교 양식(기산중 결석신고서 hwpx)대로 채워진 신고서를 A4로 인쇄할 수 있어요.

## 쓰는 법

1. `index.html`을 브라우저(크롬·엣지)로 열어요. 설치는 필요 없어요.
2. 첫 화면에서 **명단 붙여넣고 시작**을 눌러요. 엑셀에서 `번호 · 이름` 두 칸을 복사해 붙이면 돼요. 미리 둘러보려면 **예시 반으로 둘러보기**를 눌러요. 예시 반은 저장되지 않아요.
3. **출결판**
   - **하루(교시별)**: 나이스 화면처럼 조회·1~7교시·종례 칸이 보여요. 이름이나 칸을 누르면 입력 창이 떠요.
   - **한 달(학생별)**: 한 달 출결과 학생별 횟수, 덜 받은 서류가 모여요. 이름을 누르면 그 학생의 한 달 기록(날짜·출결·교시·사유·서류)이 목록으로 나와요.
4. **입력 창**: 구분(질병·출석인정·기타·미인정) → 종류(결석·지각·조퇴·결과) → 저장.
   - 지각·조퇴·결과는 **시각**에 맞춰 교시가 자동으로 체크돼요. 예) 11:42 지각 → 조회~3교시. 칸을 눌러 더하거나 뺄 수 있어요.
   - 결석은 기간을 −/+로 늘려요. 주말은 빼고 세요.
   - 사유와 첨부 서류는 비워도 돼요. 비우면 신고서에 빈칸으로 나가요.
5. **사유 칸**은 눌러서 바로 고쳐요. 누르면 전에 쓴 사유가 목록으로 뜨고, ×를 누르면 목록에서 지워져요(이미 쓴 기록은 그대로예요).
6. **서류함**: 질병·출석인정·기타 출결이 모여요. 왼쪽에서 고르고 **체크한 N장 인쇄**를 누르면 인쇄 창이 떠요. PDF로 저장도 돼요.
   - 질병 → 질병 신고서, 출석인정 → 출석인정 신고서, 기타 → 학부모 의견서 + 담임교사 의견서, 미인정 → 신고서 없음
   - 기타는 서류함의 **뽑을 장**에서 학부모 의견서만, 또는 담임교사 의견서만 고를 수 있어요.
   - 기간은 결석이면 `○월 ○일부터 / ○월 ○일까지 ( )일간`, 지각이면 `( )교시까지`(빠진 마지막 교시), 조퇴면 `( )교시부터`(빠지기 시작한 교시), 결과면 `( )교시`로 들어가요.
   - 이름은 `김 나 래`처럼 한 칸씩 띄워 들어가요.
   - 작성일, 기간의 ( )일간·( )교시, 사유, 첨부 서류는 서류함에서 고칠 수 있어요.
   - **빈 양식**으로 손으로 쓸 빈 신고서(질병·출석인정·학부모 의견서·담임교사 의견서)도 뽑을 수 있어요.
7. **설정**: 학교 이름, 학년·반·담임, 교시 시작 시각(조회 09:00, 1교시 09:15 …), 요일별 시간표, 명단, 오프라인 상태, 백업.

가이드는 처음 출결판에 들어왔을 때 한 번만 저절로 떠요. 다시 보려면 오른쪽 위 **가이드 보기**를 눌러요.

## 인터넷이 없을 때

- 따로 켤 것은 없어요. 웹 주소로 **인터넷이 될 때 한 번** 열면, 앱 파일과 글꼴이 이 브라우저에 저장돼요(머리줄에 '오프라인 준비됨'이 떠요). 지금 상태는 **설정 → 오프라인** 칸에서 볼 수 있어요.
- 그다음부터는 인터넷이 끊겨도 **같은 주소로** 열리고 입력·저장·서류함·인쇄가 다 돼요. 인터넷이 끊기면 머리줄에 '인터넷 없음 · 계속 쓸 수 있어요'가 떠요.
- 앱을 고쳐서 다시 올리면, 다음에 인터넷이 될 때 새 버전으로 바뀌어요.
- 처음 한 번은 꼭 인터넷이 될 때 열어야 해요. 다른 컴퓨터·다른 브라우저도 처음엔 마찬가지예요.
- `index.html`을 파일로 열어도 인터넷 없이 돼요. 다만 웹 주소에서 쓴 기록과 파일로 연 기록은 **따로** 저장되니 한 가지로만 쓰세요.

## 저장과 개인정보

- 명단과 기록은 **이 컴퓨터의 이 브라우저에만** 저장돼요(localStorage). 서버로 보내지 않아요.
- 브라우저 기록을 지우거나 다른 컴퓨터에서 열면 보이지 않아요. **설정 → 백업 파일 받기**로 가끔 받아 두고, 다른 컴퓨터에서는 **백업 불러오기**를 써요.
- 백업 파일(.json)에는 학생 이름이 들어 있으니 저장소에 올리지 마세요.
- 나이스 정식 입력은 따로 해야 해요.

## 인쇄

- A4, 여백 없음으로 인쇄돼요. 인쇄 창에서 '머리글과 바닥글'은 끄고, 배율은 '기본(100%)'으로 두세요.
- 글꼴은 앱 폴더(`fonts/`)에 들어 있어서 인터넷 없이도 신고서가 같은 모양으로 나와요. 신고서는 나눔명조, 화면은 프리텐다드예요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인, 신고서 종이(mm 단위), 인쇄 설정 |
| `app.js` | 출결판·입력 창·서류함·신고서 양식·설정·가이드 |
| `sw.js` | 오프라인 저장(서비스 워커). 글꼴을 바꾸면 안의 `CACHE` 이름 숫자를 올려요 |
| `fonts/` | 나눔명조(한글 전체, 400·700·800)·프리텐다드(400~800). 둘 다 SIL OFL 1.1, 라이선스 파일 같이 있음 |

## 인터넷에 올리기 (Cloudflare)

주소: **https://chulgyeol-note.kbe950107.workers.dev**

이 폴더만 따로 Cloudflare Workers(`chulgyeol-note`)에 올려요. `main`에 커밋이 들어오면 1~2분 뒤 저절로 다시 배포돼요. 배포 설정은 `wrangler.jsonc`, 올리지 않을 파일은 `.assetsignore`에 있어요.

**처음 한 번 (GitHub 연결, 추천)** — 그다음부터는 `main`에 커밋이 들어오면 저절로 다시 배포돼요.
1. Cloudflare 대시보드 → **Workers & Pages → Create → Import a repository** → `bon17/small_app` 고르기
2. Project name: `chulgyeol-note`
3. **Advanced settings → Root directory(Path)**: `apps/chulgyeol-note`
4. Build command는 비우고, Deploy command는 `npx wrangler deploy` 그대로 → **Deploy**
5. 주소: `https://chulgyeol-note.<계정 하위 도메인>.workers.dev` (교실 서랍과 같은 하위 도메인)

**직접 올리기 (터미널)**: 이 폴더에서 `npx wrangler deploy`

주소가 생기면 교실 서랍(허브)의 `apps.js`에 추가해요.
