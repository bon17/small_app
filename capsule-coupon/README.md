# 캡슐 뽑기권 만들기

구글시트에 정리된 캡슐 뽑기 대기 명단(엑셀)을 불러와서, 학생별 **캡슐 뽑기권**을 A4로 출력하는 앱입니다.
기프티콘처럼 떼는 점선과 반원 홈이 있는 귀여운 쿠폰 모양이에요.

## 쓰는 법

1. `index.html` 파일을 브라우저(크롬·엣지 권장)로 엽니다. 설치는 필요 없고, 인터넷이 없어도 동작해요.
2. 구글시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 로 명단을 저장한 다음, 앱의 **엑셀 파일 선택**에 넣습니다.
3. 쿠폰 설정을 확인합니다.
   - 학교 이름: 기본값 `기산중학교`
   - 안내 문구: 기본값 `본교무실에 캡슐 뽑으러 오세요~`
   - 발급일: 기본값 오늘
   - 유효기간: 기본값 2주 뒤. 비우면 쿠폰에 표시하지 않아요.
   - A4 한 장에 들어갈 쿠폰 수: 8 / 10 / **12(기본)** / 16 / 24장
   - 캡슐 그림
4. 학생을 고릅니다.
   - 줄을 누르면 선택되고, 미리보기도 그 학생으로 바뀝니다.
   - 학번·이름 검색과 상태 필터(예: 예약, 지급완료)로 목록을 좁힐 수 있어요.
5. 출력 버튼을 누릅니다.
   - **선택한 학생 출력**: 체크한 학생만 출력합니다.
   - **목록 전체 출력**: 지금 목록에 보이는 학생을 모두 출력합니다.
6. 인쇄 창에서 용지는 **A4**, 배율은 **기본값(100%)** 으로 두고 인쇄합니다. 점선을 따라 자르면 됩니다.

## 엑셀 형식

- 위쪽 30줄 안에서 `이름`(또는 `성명`) 제목이 있는 줄을 찾아 그 아래를 명단으로 읽습니다.
- `학번`, `상태` 제목도 있으면 함께 읽어요. 열 순서나 숨긴 열은 상관없습니다.
- 지금 쓰는 시트의 `학번 | 이름 | 상태 | 예약 시각 | 지급 시각` 형식 그대로 쓸 수 있어요.
- 시트가 여러 개면 제목 줄이 있는 시트만 골라서 보여 주고, 위쪽에서 시트를 바꿀 수 있어요.
- 이름이 빈 줄은 건너뛰고, 학번이 겹치는 줄에는 `학번 중복` 표시를 붙입니다.
- 일련번호(No.)는 엑셀에 적힌 순서대로 001부터 붙어요. 다시 출력해도 같은 학생은 같은 번호가 나옵니다.
- `.csv` 파일도 읽을 수 있어요.

## 개인정보

- 엑셀 파일은 브라우저 안에서만 읽고, 어디로도 전송하지 않습니다.
- 이 폴더의 `.gitignore`는 `*.xlsx`, `*.xls`, `*.csv` 파일을 제외합니다. 학생 명단이 실수로 저장소에 올라가지 않게 하려는 거예요.
- 브라우저에 저장되는 것은 학교 이름, 안내 문구, 한 장당 쿠폰 수, 직접 바꾼 캡슐 그림뿐입니다. 학생 명단은 저장되지 않아요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체(화면, 쿠폰 디자인, 인쇄). 글꼴·엑셀 라이브러리·기본 캡슐 그림이 파일 맨 아래에 들어 있어서 이 파일 하나만 있으면 됩니다. |
| `assets/capsule.webp` | 기본 캡슐 그림 원본 |
| `licenses/` | 함께 넣은 글꼴과 라이브러리의 라이선스 |
